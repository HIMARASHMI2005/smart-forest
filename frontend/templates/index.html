System Capabilities

🧠

Custom AI — Zero Pretrained Weights

ForestPersonNet and ForestFaceNet are built and trained entirely from scratch using Kaiming random initialization. No YOLO, FaceNet, or any pretrained checkpoints.

📹

Real-Time Person Detection

Webcam frames are analyzed by ForestPersonNet — a custom object-detection CNN — providing bounding boxes and confidence scores at inference time.

👤

Face Identification

ForestFaceNet extracts 128-D face embeddings for registered forest personnel. Unknown individuals trigger immediate alerts to the command center.

🗺️

GPS Geo-Fencing

Browser GPS + Shapely polygon math enforce zone boundaries. Unauthorized entries into HIGH/CRITICAL zones produce instant SocketIO alerts.

🆘

Emergency SOS System

One-tap SOS broadcasts the user's GPS location, emergency type, and message to the admin command center via WebSocket in real time.

📊

Admin Command Center

Live dashboard with detection history, alert management, SOS resolution, zone configuration, and user management.
